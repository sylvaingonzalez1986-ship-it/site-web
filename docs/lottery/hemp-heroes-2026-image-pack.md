# Hemp Heroes 2026 Image Pack

## Usage

- `hemp-heroes-2026-cards.json`: importable payload aligned with the admin card API.
- `hemp-heroes-2026-cards.csv`: spreadsheet-friendly version of the same catalog.
- This document: global art direction plus all 52 prompts grouped by rarity.

## Global Direction

- Format: vertical `2:3` collectible card illustration.
- Era: `1930s retro cartoon`, `rubber hose animation`, `Cuphead-inspired aesthetic`.
- Character base: anthropomorphic CBD hemp flower character, `large expressive black pie-cut eyes`, `big cheerful smile`, `thin black noodle arms and legs`, `thick white worker gloves`, `oversized vintage shoes`.
- Rendering: `very thick black outlines`, `clean vector-like lineart`, `flat colors`, `subtle retro halftone stippling dots for shadows`.
- Composition: one strong central character, one main accessory or visual gag, high readability at small size.
- Backgrounds: bright, minimal, lightly themed, never overloaded.

## Rarity Rules

- `legendary`: sacred, singular, mythic, strongest premium aura.
- `epic`: theatrical, heroic, elevated, dramatic but still playful.
- `gold`: premium, flashy, energetic, vibrant and fun.
- `silver`: refined, poised, elegant, polished vintage charm.
- `common`: simple, immediate, friendly, one clean visual gag.

## Negative Prompt

Use this suffix for every generation: `No text, no logo, no border, no card frame, no watermark, no interface, no extra characters, no realistic rendering, no 3D look.`
