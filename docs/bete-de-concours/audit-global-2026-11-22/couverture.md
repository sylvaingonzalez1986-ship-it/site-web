État de l’arbre de travail du 22 novembre 2026. « Joué » désigne un geste dans Chrome sur les composants du dépôt et des comptes fictifs. « Moteur » désigne un calcul TypeScript ou une transaction SQL locale. ## Reproduire les vérifications complémentaires

Lancer depuis la racine. Les parcours de l’école utilisent une prévisualisation isolée des API de comptes, sur le port de boucle locale 3662. Le second terminal utilise Chrome installé sur le poste. Le fichier de résultats consigne les temps, la largeur et le texte effectivement affiché. Un chronométrage inclut le geste automatisé, le chargement de modules Vite et l’attente du contenu.

```powershell
$env:NAVIGATION_AUDIT_PORT='3662'
node scripts/audit-placard-navigation.mjs --school-visual --preview
# Second terminal
node docs/bete-de-concours/audit-global-2026-11-22/parcours-ecole.mjs
```
